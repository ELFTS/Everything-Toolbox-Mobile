### 功能特点
- 🖥️ 横屏适配 - 横屏时显示侧边导航栏，图标在上文字在下
- 📱 底部导航栏 - 主页/工具/设置
- 🔍 搜索功能 - 快速搜索工具
- 🎨 Material Design - 现代简洁界面，支持 8 种主题颜色
- 📊 实时系统监控 - CPU和内存使用率实时更新

## ✨ 软件功能

### 主页
- 💻 系统状态 - CPU和内存使用率（进度条显示，实时更新）
- 📱 设备信息 - 网格卡片布局展示：品牌、型号、Android版本、SDK版本、处理器、CPU核心数、屏幕分辨率、屏幕密度、总内存、可用存储
- 🔍 完整设备信息 - 点击"查看完整信息"进入类似AIDA64的详细设备信息页面，包含8个分类选项卡（设备、系统、CPU、内存、存储、屏幕、网络、其他）
- 💬 一言 - 随机一言API

### 工具
- 🔋 电池信息 - 查看电池状态、电量、温度、电压、健康度等
- 📶 Wi-Fi信息 - 查看Wi-Fi连接详情（SSID、信号强度、频率、IP地址、MAC地址等）
- 🌐 IP查看 - 查看本机IPv4/IPv6地址和公网IP地址及位置
- 📱 设备信息 - 查看完整设备硬件信息（类似AIDA64），包括设备、系统、CPU、内存、存储、屏幕、网络等详细信息

### 设置
- ⚙️ 个性化 - 主题配色选择（青色、蓝色、绿色、紫色、橙色、红色、粉色、灰色）
- ℹ️ 关于 - 应用信息、开发团队、用户协议、隐私政策
- 🎮 彩蛋 - 连续点击Logo 10次触发惊喜
